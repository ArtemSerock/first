# first
Это мой первый репозиторий в котором реализовано 3 алгоритма. Немного о них:

FizzBuzz - Эта функция выводит числа от 1 до 100 с некоторым отличием: числа, кратные 3 заменяются на Fizz, кратные 5 на Buzz, а кратные и 3, и 5 на FizzBuzz

QuickSort - Самые быстрый алгоритм сортировки чисел в массиве(из ивестных мне) 

Prime_divs = Этот алгоритм находит все простные делители числа n(простой делитель - это число, на которое нацело делиться число n и является простым)
